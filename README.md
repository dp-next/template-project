This repository contains a
[Copier](https://copier.readthedocs.io/en/stable/) template for setting
up a new repository for a data analysis-based research project in
DP-Next. We made template-project to make it easier for researchers to
get started with doing a research project within DP-Next. So we’ve
designed this template to make it easier to create, develop, and
maintain those types of projects.

Check out our [website](https://dp-next.github.io/template-project/) for
more information, such as the features it provides and a
[guide](https://dp-next.github.io/template-project//docs/guide) to using
the template. For a list of changes, see our [changelog](CHANGELOG.md)
page.
