# Contents of docs folder

This folder should contain the main scientific product of the project as
well as all other files related to it (e.g. co-author comments,
versions, images, etc). It may and likely should also contain
supplementary and exploratory Quarto files. Once submission or
presentation time has come for the product, files associated with that
process (e.g. response to reviewers) should be placed in here.

Each specific folder should only contain files that are relevant to making that
particular file as a PDF (e.g. only protocol files in the `protocol/` folder).
The `sandbox/` folder is where you can do whatever you want, make whatever files
you want to test out and play around with. Treat the `sandbox/` folder as
temporary that can be deleted at any time.
